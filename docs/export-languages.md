# Exports in other languages

An exported Word or PDF file prints its fixed words in the language the summary is written in. That is the spoken language when a recording has exactly one language, and English otherwise. The fixed words are the part headings (Summary, Action points…), the Approved/Draft marker, the details table, page numbers, a letter's "Our ref:", and the approval box.

- **Translated:** French, Spanish, German, Italian, Dutch, Polish, Russian, Ukrainian, Afrikaans, Chinese, Japanese and Arabic. Dates use that language's month names.
- **English:** Maltese, isiZulu and any other language. The names of the spoken languages in the details table also stay in English.
- **Minutes templates:** a heading you typed yourself is printed exactly as you typed it. A heading left as VerbaFlow's English default is translated.
- **Arabic, Chinese and Japanese PDFs:** VerbaFlow uses a font on the computer that has these letters and builds it into the PDF. On Windows that is Arial or Tahoma for Arabic, Microsoft YaHei for Chinese, and Yu Gothic or Meiryo for Japanese. Arabic letters are joined and read from right to left. If the computer has no such font, those letters show as empty boxes, but the export still works.
- **Word files:** Arabic paragraphs are marked as right to left. Word picks its own font for Chinese and Japanese.

The translations were written by VerbaFlow's developers and have not been checked by native speakers. Please report any wording that looks wrong.
